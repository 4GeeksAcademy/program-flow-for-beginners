# 1. Secuencias básicas

## :movie_camera: Escenario
Estás preparando café antes de clase. Dibuja una línea recta de pasos desde Inicio hasta Fin: por ejemplo, hervir agua, preparar el café y servirlo. No hay decisiones ni bucles.

## :memo: Instrucciones
1. Abre `app.js` en la carpeta de este ejercicio.
2. Usa este **[Editor Mermaid](https://waficmikati.github.io/mermaid/)** para crear tu diagrama.
3. Pega el código Mermaid dentro de `answer`. No cambies el nombre de `answer` ni de `module.exports` en `app.js`.

## :mag: Cómo se revisa tu diagrama
- Todas las cajas deben estar conectadas: un Inicio, un Fin y flechas entre ellos.
- Ninguna caja puede dividirse en dos flechas (sin decisiones).
- El agua tiene que calentarse antes de preparar o servir el café, y el café tiene que prepararse antes de servirse.

## :bulb: Pista
- Escribe cada paso como una acción corta: **Hervir agua**, **Preparar el café**, **Servir el café**.
