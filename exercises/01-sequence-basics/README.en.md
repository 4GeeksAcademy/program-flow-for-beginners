# `01` Sequence Basics

Scenario: You are preparing coffee before class. Define a simple linear flow from start to end with intermediate steps (for example: boil water, brew coffee, serve). No decisions.

## :memo: Instructions
1. Open `app.js` in this exercise folder.
2. Use the app https://waficmikati.github.io/mermaid/ to create your Mermaid diagram.
3. Keep core nodes and branch conditions aligned with the rubric; equivalent edge layouts are accepted when flow logic is preserved.
4. Do not rename `answer` or `module.exports` in `app.js`.

## :bulb: Hint
- Your graph should include these key concepts: start, end.
- Aim for at least 3 edges in total before running tests.
- This exercise does not require branch condition labels.
- Avoid forbidden patterns in the diagram text: while, for.
- The rubric validates flow structure; coffee steps are the narrative guide.
