# 1. Sequence Basics

## :movie_camera: Scenario
You are preparing coffee before class. Draw a straight line of steps from Start to End: for example boil water, brew coffee, serve. There are no decisions and no loops.

## :memo: Instructions
1. Open `app.js` in this exercise folder.
2. Use this **[Mermaid Editor](https://waficmikati.github.io/mermaid/)** to create your diagram.
3. Paste the Mermaid code inside `answer`. Do not rename `answer` or `module.exports` in `app.js`.

## :mag: How your diagram is checked
- Every box must be connected: one Start, one End, and arrows in between.
- No box may split into two arrows (no decisions).
- The water has to be heated before you brew or serve, and the coffee brewed before it is served.

## :bulb: Hint
- Write each step as a short action: **Boil water**, **Brew coffee**, **Serve coffee**.
